Title: [Product List]: "Sorting is broken!" system error appears when applying "Price (low to high)" filter
Environment: macOS, Safari
Severity / Priority: Major / High
Steps to Reproduce:
Log in to Swag Labs with valid credentials.
Navigate to the main "Products" page.
Click on the sorting dropdown menu in the top right corner.
Select the "Price (low to high)" option.
Expected Result: The product list is immediately sorted by price in ascending order.
Actual Result: An alert dialog appears displaying "Sorting is broken! This error has been reported to Backtrace.". The products remain unsorted.
